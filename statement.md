# Project Statement

## Project Title
Student Academic Management & Performance Analysis System

## Problem Statement
Academic records are often scattered across unrelated files, making validation and performance analysis difficult. This project provides one coherent terminal application for maintaining and interpreting those records.

## Scope
Local management of students, courses, enrollments, marks, attendance, and summary reports. Authentication, networking, and institutional-scale databases are outside scope.

## Target Users
College or university administrators and teaching staff working with a small academic dataset.

## High-Level Features
CRUD operations, search and sort, enrollment integrity, grading, attendance alerts, performance reports, CSV persistence, validation, and automated tests.

## Technologies
Java 17, Maven, JUnit 5, Java Collections, Java I/O, and built-in logging.

## Expected Outcome
A complete, executable, understandable Java application that reliably persists academic data and turns it into useful reports while demonstrating core programming concepts.
